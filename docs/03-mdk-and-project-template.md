# 第 03 章 MDK 软件与工程模板创建

## 3.1　为什么工程里需要库文件

Keil MDK 是编写、构建和调试程序的开发工具，µVision 是它的开发界面。**CMSIS** 提供访问 Cortex 内核的统一接口，ST 的**标准外设库**把 GPIO、定时器等外设的寄存器操作写成可调用的函数。

## 3.2　工程里最常见的文件

| 文件 | 看见它时想到什么 |
| --- | --- |
| `startup_stm32f10x_hd.s` | 大容量 F103 的启动文件，提供复位入口和中断向量表 |
| `system_stm32f10x.c` | 系统初始化，包括时钟设置 |
| `main.c`、`stm32f10x_it.c` | 前者放应用主程序，后者通常放中断服务函数 |
| 外设的 `.h` 和 `.c` | 头文件声明函数和类型，源文件提供实现。例如 GPIO 驱动就有这样一对文件 |

`#include "stm32f10x_gpio.h"` 可以注释为“引入 GPIO 驱动声明，使本文件能使用相关类型和函数”。真正改变引脚状态的是运行时执行的外设操作。

## 3.3　编译、链接、下载和仿真

**编译**把各个源文件变成目标文件。**链接**把这些目标文件和库组成可执行程序，找到每个被调用函数的实现。**下载**把生成的程序写入芯片。**仿真**让程序在软件模型中运行，课件用 Logic Analyzer 观察 `PORTC.0` 的高低电平变化。
