# 第 09 章 定时器与脉冲宽度调制

[总目录](../README.md#章节目录)

## 9.1～9.4 定时器类型

| 类型 | 课件芯片上的定时器 | 主要用途 |
| --- | --- | --- |
| 基本定时器 | TIM6、TIM7 | 向上计数、周期定时，可触发 DAC |
| 通用定时器 | TIM2～TIM5 | 定时、输入捕获、输出比较、PWM |
| 高级定时器 | TIM1、TIM8 | 还支持互补输出、死区和刹车等功能 |

**输入捕获**是在输入边沿记录计数值，可用来测时间或频率。**输出比较**是用当前计数与比较值比较，满足条件时改变输出。

## 9.5 定时器的周期

| 寄存器 | 作用 |
| --- | --- |
| `PSC` | 预分频值，实际分频系数为 `PSC + 1` |
| `ARR` | 自动重装值，向上计数从 0 数到 ARR，一个周期计 `ARR + 1` 次 |
| `CNT` | 当前计数值 |
| `CCR` | 捕获或比较值，用于测输入和控制输出 |

向上计数的**更新周期 = (PSC + 1) × (ARR + 1) ÷ 定时器输入时钟**。计算时用定时器的输入频率，单位用 Hz。APB 分频为 1 时定时器时钟等于 PCLK，分频大于 1 时本章定时器用两倍 PCLK。

课件的一秒例子用 72 MHz、PSC=1999、ARR=35999。`2000 × 36000 ÷ 72000000 = 1 s`。每次中断翻转一次引脚时，经过一段高电平和一段低电平才是一个方波周期。

## 9.6 PWM

**PWM 是脉冲宽度调制。** 频率表示每秒重复几次，占空比表示某一电平持续时间占周期的比例。固定时钟和 PSC、ARR 后，改变 CCR 可调节脉宽。向上计数的 PWM1 中，`CNT < CCR` 的区间有效，输出高还是低取决于极性。有效区间占比为 `CCR ÷ (ARR + 1)`。

`TIM_Cmd` 启停定时器，`TIM_ITConfig` 配置指定的中断请求。`TIM_SetCompare1` 改通道 1 的比较值。
