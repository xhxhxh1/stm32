# 第 09 章 定时器与脉冲宽度调制

## 9.1～9.4　三类定时器各做什么

| 课件芯片上的定时器 | 主要用途 |
| --- | --- |
| 基本 TIM6、TIM7 | 向上计数，产生周期性更新，可用来定时或触发 DAC |
| 通用 TIM2～TIM5 | 除定时外，还能用输入捕获测脉宽、用输出比较或 PWM 产生波形 |
| 高级 TIM1、TIM8 | 增加互补输出、死区和刹车等功能，常见于电机控制 |

## 9.5～9.6　怎样算出一秒

把**定时器输入时钟**记作 `f_TIM`。`PSC` 是预分频值，每经过 `PSC + 1` 个输入时钟，当前计数值 `CNT` 加 1。向上计数时，`CNT` 从 0 数到自动重装值 `ARR` 再回到 0，一轮共有 `ARR + 1` 次计数。

**更新周期**　`T = (PSC + 1) × (ARR + 1) / f_TIM`

课件的 TIM6 示例取 `PSC = 1999`、`ARR = 35999`。当 `f_TIM = 72 MHz` 时，先用 72 MHz 除以 2000 得到 36 kHz，再数 36000 次，正好 **1 秒**。这里要用 TIM6 的时钟。常见配置中 APB1 为 36 MHz，因 APB1 分频系数为 2，定时器输入为 72 MHz。[ST 时钟说明](https://www.st.com/resource/en/reference_manual/rm0008-.pdf)

## PWM　频率和占空比各由什么决定

PWM 用周期脉冲控制负载。**频率**是一秒重复多少次，**占空比**是所考察的电平在一个周期中所占的比例。固定时钟、PSC 和 ARR 后，改变比较值 `CCR` 就能调脉宽。课件把 TIM3 的两个通道重映射到 PC6、PC7，让两盏灯渐亮、渐暗。

```c
TIM_SetCompare1(TIM3, 300);  // 把 TIM3 通道 1 的比较值设成 300，改变该通道的脉宽
```

例如向上计数、PWM 模式 1、`ARR = 899` 时，有效区间为 300/900，约 **33.3%**。有效区间输出高还是低取决于输出极性，课件 LED 在低电平期间发光。
