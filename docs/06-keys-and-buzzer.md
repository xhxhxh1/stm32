# 第 06 章 按键输入与蜂鸣器

## 6.1 GPIO 输入读取

| 函数 | 读取内容 |
| --- | --- |
| `GPIO_ReadInputDataBit` | 一个引脚的输入电平 |
| `GPIO_ReadInputData` | 整个端口的输入值 |
| `GPIO_ReadOutputDataBit` | 一个引脚的输出锁存值 |
| `GPIO_ReadOutputData` | 整个端口的输出锁存值 |

`ReadInput` 对应 IDR，`ReadOutput` 对应 ODR。带 `Bit` 的函数读一个引脚，结果是 0 或 1。整个端口的读数是 16 位，每一位对应一个引脚。

## 6.2 按键电平与消抖

课件板 KEY1～KEY4 分别接 PE0～PE3，按键另一端接地。设置**上拉输入**后，松开读 1，按下读 0。

读一个键时选对应的输入位。比如 KEY2 接 PE1，读到 0 就表示它被按下。若一次读取整个 GPIOE，只需看低四位。四个键都松开时低四位是 `1111`，只有 KEY2 按下时是 `1101`。

机械触点开合时会短暂抖动，按一下可能被读出多次变化。软件消抖的基本方法是第一次检测到按下后，短暂等待，再确认电平是否稳定。要让一次按下只触发一次，还需等按键稳定松开后再接受下一次按下。

## 6.3 蜂鸣器

- **有源蜂鸣器**内部有振荡电路，按额定条件供电即可发出音调。
- **无源蜂鸣器**需要周期性驱动。课件板用 PC8 控制 PNP 三极管，PC8 低电平时导通，高电平时截止。
- 高、低电平各保持 1 ms 时，一次完整通断周期为 2 ms，频率是 500 Hz。改变通断频率可以改变音调。

课件程序先用 `BeepInit` 把 PC8 设为通用推挽输出，再用 `KeyInit` 配置按键输入。`BeepKey` 读键并按结果调用发声函数，`sound1` 和 `sound2` 通过不同的通断节奏发声。
