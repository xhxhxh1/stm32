# 第 06 章 按键输入与蜂鸣器

## 6.1　读按键要看输入电平

课件按键一端接地，另一端接 PE0～PE3。配置为**上拉输入**后，松开时引脚为高，按下时引脚被接到地。读到 0 表示按下。

| 函数 | 读到的值 |
| --- | --- |
| `GPIO_ReadInputDataBit` | 一个引脚的输入电平，读按键用它 |
| `GPIO_ReadInputData` | 整个端口的输入电平 |
| `GPIO_ReadOutputDataBit` | 一个引脚的输出锁存值 |
| `GPIO_ReadOutputData` | 整个端口的输出锁存值 |

```c
level = GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_0);  // 读 KEY1 所接的 PE0，上拉时按下读 0
```

## 6.2～6.3　一次按键怎样控制声音

**消抖**　机械触点在按下或松开瞬间可能反复接触。第一次读到低电平后，稍等再读一次，稳定为低才确认按下。如果要求“一按只算一次”，还要等它松开后再接受下一次按下。

**无源蜂鸣器**需要周期性驱动。PC8 控制 PNP 三极管，低电平使它导通，高电平使它截止。程序让 PC8 高低交替就能发声。交替越快，驱动频率越高，音调通常越高。例如低电平和高电平各持续 1 ms，一个周期为 2 ms，对应 500 Hz。
