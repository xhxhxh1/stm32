# 第 08 章 中断系统与基本应用

[总目录](../README.md#章节目录)

## 8.1 中断、中断源与事件

**中断**是 CPU 暂停当前程序，按中断向量表找到服务函数，处理后返回继续执行。按键、定时器到时、串口收到数据都可以产生中断请求。系统异常和软件触发也属于本章讨论的中断来源。

**中断与事件**可以来自同一个外部边沿，也可以由软件触发。中断路径要让 CPU 执行服务函数。事件路径可直接产生硬件事件信号，减少 CPU 的处理工作。

## 8.2 NVIC 与优先级

**NVIC** 负责中断使能、分组和优先级管理。课件题目中的 **84 个中断源**按 16 个内核位置与 68 个外部位置相加。

| 情况 | 响应规则 |
| --- | --- |
| 两个请求同时到达 | 优先级数值越小越高。题设抢占值是 0 和 2、CPU 正在运行主程序时，**0 先响应，2 等待** |
| 低优先级中断已经在执行 | 抢占优先级更高的中断可以打断它 |
| 高优先级中断正在执行 | 低抢占优先级的请求等待 |
| 抢占级相同 | 同时等待时，响应优先级较高的先执行。同抢占级之间不能互相打断 |
| 抢占级和响应级都相同 | 同时等待时，按异常编号排序，小的先处理 |

抢占优先级也叫**占先式优先级**，响应优先级也叫**副优先级**。两类优先级共用 **4 位**，有 **16 种编码**。标准库分组通常在初始化时统一设置。

| 优先级分组 | 抢占优先级位数 | 响应优先级位数 |
| --- | --- | --- |
| 0 | 0 | 4 |
| 1 | 1 | 3 |
| 2 | 2 | 2 |
| 3 | 3 | 1 |
| 4 | 4 | 0 |

分组 1 的抢占值是 **0～1**，响应值是 **0～7**。

## 8.3～8.5 EXTI 外部中断

- **19 条线、16 条 GPIO 线**　EXTI 有 19 个边沿检测器，EXTI0～EXTI15 可接 GPIO。同编号的 PA0、PE0 只选一个接 EXTI0。
- **分开记共用入口**　EXTI0～EXTI4 各有入口。EXTI5～EXTI9 共用 `EXTI9_5`，EXTI10～EXTI15 共用 `EXTI15_10`。
- **分开记部件**　GPIO 读取电平，AFIO 选择引脚映射，EXTI 检测边沿，NVIC 管中断通道和优先级。
- **触发和标志**　EXTI 可选上升沿、下降沿或双边沿。课件上拉按键按下时是 1 到 0，选下降沿。`IMR` 管中断屏蔽，`PR` 记录挂起，`EXTI_ClearITPendingBit` 清指定挂起标志。
