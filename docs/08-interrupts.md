# 第 08 章 中断系统与基本应用

## 8.1～8.2　中断和优先级

**中断**让 CPU 在事件发生时暂停当前任务，保存现场，按向量表找到中断服务函数，处理后再返回。这样主程序可以继续扫描数码管，按键按下时再去调时间。中断服务函数要短，以便及时返回。

**NVIC** 管理中断通道和优先级。STM32F103 用 4 位可编程优先级，分组决定其中几位用于抢占、几位用于响应。数值越小，优先级越高。

| 优先级 | 决定什么 |
| --- | --- |
| 抢占优先级 | 抢占优先级更高的请求，可以打断正在运行的较低优先级中断 |
| 响应优先级（子优先级） | 抢占优先级相同、多个请求同时等待时，决定先处理哪一个。同抢占级的中断互相等待 |

## 8.3～8.5　从按下按键到进入服务函数

1. 开启 GPIOE 和 AFIO 的时钟，把 PE0 配为上拉输入，并通过 AFIO 把 PE0 映射到 EXTI0。
2. **EXTI** 检测边沿。上拉按键按下是 1 变 0，应选下降沿。松开是上升沿，也可以配置为双边沿。
3. 在 EXTI 开放该线的中断请求，在 NVIC 使能对应通道。触发后进入 `EXTI0_IRQHandler`，判断来源，处理本次请求并清除挂起位。

EXTI 的**中断**路径经 NVIC 请求 CPU 执行服务函数，**事件**路径则可以发出硬件事件脉冲。引脚编号决定可选的外部线，例如 PA0 和 PE0 都对应 EXTI0，同一时刻该线只选其中一个端口。

```c
EXTI_ClearITPendingBit(EXTI_Line0);  // 清除 EXTI0 本次中断的挂起标志
```
