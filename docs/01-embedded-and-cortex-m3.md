# 第 01 章 ARM Cortex-M3 嵌入式系统

## 1.1　什么是嵌入式系统

嵌入式系统是装在某种设备里、为特定任务设计的计算机系统。比如洗衣机的控制器要读水位、控制电机，这些任务决定它需要哪些硬件和软件。通用计算机则要适应许多不同的应用。

课件中的几个特点都能从这个例子理解。**专用**指围绕产品的功能设计，**可裁剪**指只选需要的软硬件，**实时**指在规定时间内响应，**可靠**指长期稳定地工作。成本、体积和功耗也会影响设计。

## 1.2～1.3　ARM、Cortex-M3 和 STM32 的关系

| 名称 | 记住什么 |
| --- | --- |
| ARM | 提供处理器架构和内核设计 |
| Cortex-M3 | 一种 32 位处理器内核，负责执行指令 |
| STM32F103ZET6 | ST 把 Cortex-M3、存储器和外设集成在一起制成的微控制器（MCU） |

型号里，**Z** 表示 144 引脚，**E** 表示 512 KB Flash，**T** 表示 LQFP 封装，**6** 表示 −40～85 ℃。开发板再把这颗芯片接到电源、按键、LED 等器件上。

## 1.4　软件怎样运行

简单的裸机程序在上电后初始化硬件，再进入主循环。读到 `while (1)`，可以注释为“反复执行循环体中的任务”。任务多时，也可以使用操作系统，由它安排各任务在什么时候运行。
