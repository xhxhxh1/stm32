## 1.1 嵌入式系统

**嵌入式系统**是以应用为中心、软硬件可裁剪的专用计算机系统。设计时要考虑功能、实时性、可靠性、成本、体积和功耗。洗衣机、门禁、工业控制器都是常见应用。

嵌入式系统和通用计算机都由**硬件和软件**组成。嵌入式系统通常装在具体产品里，按任务配置资源。通用计算机的资源和软件面向多种任务。

| 概念 | 基本含义 |
| --- | --- |
| 专用性 | 围绕设备的一项或一类任务设计 |
| 可裁剪性 | 根据用途配置需要的硬件和软件 |
| 实时性 | 在规定时间内完成响应 |
| 可靠性 | 能按要求稳定运行 |
| 生命周期 | 嵌入式系统通常跟随所在产品的生命周期 |
| 单片机（MCU） | 把 CPU、存储器和常用外设集成到一个芯片中 |

## 1.2～1.3 ARM、Cortex-M3 与 STM32

- **ARM** 提供处理器架构和内核设计。RISC 是**精简指令集**。Cortex-A 面向应用处理，Cortex-R 面向实时处理，Cortex-M 面向微控制器。
- **Cortex-M3** 是 32 位内核，属于 ARMv7-M，内置 NVIC 管理中断。采用哈佛结构的设计，取指和访问数据有不同总线接口。三级流水线依次是**取指、译码、执行**。
- **STM32F103** 是 ST 使用 Cortex-M3 设计的一类微控制器，片内还集成 Flash、SRAM、GPIO、定时器和串口等部件。32 位地址对应 **4 GB 的可寻址空间**，片内实际存储容量看具体型号。

## 1.4 嵌入式软件

- **裸机**　课件把软件分为引导程序和应用程序。引导程序先做时钟、外设等初始化，应用程序随后实现产品功能，通常在主循环里执行任务，也可以使用中断。
- **带操作系统**　从下到上是设备驱动层、操作系统层、应用软件层。操作系统可以调度任务、管理资源。课件中的 μC/OS-II 和 VxWorks 都是实时操作系统。嵌入式 Linux 是经过裁剪、可在嵌入式设备上运行的 Linux。
