# 第 04 章 通用目的输入输出口

## 4.1～4.5　GPIO 引脚能做什么

GPIO 是通用输入输出口。`PC0` 表示 C 端口的第 0 号引脚。用引脚读按键时选输入，用它点灯时选输出，交给串口或定时器驱动时可选复用功能。

| 模式 | 引脚怎样工作 |
| --- | --- |
| 浮空输入 / 模拟输入 | 浮空输入由外部电路决定高低，悬空时读数不稳定。模拟输入用于把模拟电压送给 ADC 等电路 |
| 上拉输入 / 下拉输入 | 外部没有驱动时，上拉默认为 1，下拉默认为 0 |
| 通用推挽 / 通用开漏 | 推挽能主动输出高、低电平。开漏能主动拉低，释放后靠上拉得到高电平 |
| 复用推挽 / 复用开漏 | 电气特性分别与推挽、开漏相同，输出信号由片内外设控制 |

读参数时，`GPIO_Mode_IPU` 是上拉输入，`GPIO_Mode_Out_PP` 是通用推挽输出，`GPIO_Mode_AF_PP` 是复用推挽输出。

`GPIO_Speed` 的 2、10、50 MHz 档位描述输出驱动速度。LED 闪烁的快慢取决于程序多久改变一次输出。**重映射**是把外设信号从默认引脚切换到芯片支持的另一组引脚。

## 4.6～4.8　从寄存器读出动作

| 寄存器 | 用途 |
| --- | --- |
| `CRL` / `CRH` | 配置 0～7 / 8～15 号引脚的模式，每个引脚占 4 位 |
| `IDR` / `ODR` | IDR 读引脚输入电平，ODR 保存输出锁存值 |
| `BSRR` / `BRR` | BSRR 低 16 位写 1 可置位，高 16 位写 1 可清位。BRR 对应位写 1 也能清位 |

使用 GPIO 时，先开端口时钟，再配置引脚模式，最后读写数据。下面的 PC0 已配置为推挽输出。

```c
GPIOC->BRR = GPIO_Pin_0;  // 清除 PC0 的输出位，课件板上的 L1 点亮
```
