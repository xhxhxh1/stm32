## 4.1～4.4 GPIO 模式和速度

GPIO 是通用输入输出口。`PC0` 表示 C 端口第 0 号引脚，每个端口的引脚编号为 0～15。STM32F103 有四种输入模式和四种输出模式。

| 类型 | 模式 | 基本特点 |
| --- | --- | --- |
| 输入 | 浮空 | 内部不上拉也不下拉，由外部信号决定电平 |
| 输入 | 上拉 | 外部未驱动时默认读高 |
| 输入 | 下拉 | 外部未驱动时默认读低 |
| 输入 | 模拟 | 用来读取模拟信号，例如 ADC 输入 |
| 输出 | 通用推挽 | 程序可控制引脚主动输出高、低电平 |
| 输出 | 通用开漏 | 程序控制引脚拉低或释放，通常靠上拉得到高电平 |
| 输出 | 复用推挽 | 由片内外设控制推挽输出，例如 USART 的 TX |
| 输出 | 复用开漏 | 由片内外设控制开漏输出，例如硬件 I²C |

GPIO 输出驱动速度有 **2 MHz、10 MHz、50 MHz** 三档。普通 GPIO 复位后默认为**浮空输入**。调试引脚另有默认用途，例如 F103C8T6 的 PB3 复位后用于 JTAG 的 JTDO。两根基本 SWD 信号为 PA13（SWDIO）和 PA14（SWCLK）。[STM32F103C8T6 引脚表](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)

## 4.5～4.6 复用和常用寄存器

**复用**是让某个引脚承担片内外设的信号。**重映射**是把外设信号换到芯片支持的另一组引脚。

| 寄存器 | 作用 |
| --- | --- |
| `CRL`、`CRH` | 配置 0～7 号、8～15 号引脚。每个引脚各占 4 位 |
| `IDR` | 读取引脚的输入电平 |
| `ODR` | 保存程序写入的输出值 |
| `BSRR` | 低 16 位写 1 可置对应输出位，高 16 位写 1 可清对应输出位 |
| `BRR`、`LCKR` | 前者清指定输出位，后者锁定端口配置 |

**使用顺序**　先使能对应 GPIO 的 APB2 时钟，再选引脚和模式，最后读写。`GPIO_SetBits` 把指定输出位设为 1，`GPIO_ResetBits` 把它清为 0。灯是亮还是灭要看板上接法。
