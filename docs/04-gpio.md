## 4.1～4.4 GPIO 模式和速度

GPIO 是通用输入输出口。`PC0` 表示 C 端口第 0 号引脚，每个端口的引脚编号为 0～15。STM32F103 有四种输入模式和四种输出模式。

GPIO 内部有输入电路和输出驱动电路。数字输入经过**施密特触发器**，再由输入数据寄存器读取电平。模拟输入走模拟通路。输入端的内部上拉或下拉，可以让外部悬空时保持确定的电平。

| 类型 | 模式 | 标准库名称 | 基本特点 |
| --- | --- | --- | --- |
| 输入 | 浮空 | `GPIO_Mode_IN_FLOATING` | 内部不上拉也不下拉，由外部信号决定电平 |
| 输入 | 上拉 | `GPIO_Mode_IPU` | 外部未驱动时默认读高 |
| 输入 | 下拉 | `GPIO_Mode_IPD` | 外部未驱动时默认读低 |
| 输入 | 模拟 | `GPIO_Mode_AIN` | 用于模拟信号，例如 ADC 输入 |
| 输出 | 通用推挽 | `GPIO_Mode_Out_PP` | 程序可控制引脚主动输出高、低电平 |
| 输出 | 通用开漏 | `GPIO_Mode_Out_OD` | 程序控制引脚拉低或释放，通常靠上拉得到高电平 |
| 输出 | 复用推挽 | `GPIO_Mode_AF_PP` | 由片内外设控制推挽输出，例如 USART 的 TX |
| 输出 | 复用开漏 | `GPIO_Mode_AF_OD` | 由片内外设控制开漏输出，例如硬件 I²C |

GPIO 输出驱动速度有 **2 MHz、10 MHz、50 MHz** 三档。普通 GPIO 复位后默认为**浮空输入**。调试引脚另有默认用途，例如 F103C8T6 的 PB3 复位后用于 JTAG 的 JTDO。两根基本 SWD 信号为 PA13（SWDIO）和 PA14（SWCLK）。[STM32F103C8T6 引脚表](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)

速度档位表示引脚的输出速度上限。信号实际多久翻转一次，要看程序或外设。课件用 LED、数码管、蜂鸣器举例，这类低速输出通常用 2 MHz 就够。

## 4.5～4.6 复用和常用寄存器

**复用**是让某个引脚承担片内外设的信号。**重映射**是把外设信号换到芯片支持的另一组引脚。

| 寄存器 | 作用 |
| --- | --- |
| `CRL`、`CRH` | 配置 0～7 号、8～15 号引脚。每个引脚占 4 位，分别是 2 位 `CNF` 和 2 位 `MODE` |
| `IDR` | 读取引脚的输入电平 |
| `ODR` | 保存程序写入的输出值 |
| `BSRR` | 低 16 位写 1 可置对应输出位，高 16 位写 1 可清对应输出位 |
| `BRR`、`LCKR` | 前者清指定输出位，后者锁定端口配置 |
| `RCC_APB2ENR` | APB2 外设时钟使能寄存器，例如 `IOPCEN` 置 1 打开 GPIOC 时钟 |

`MODE = 00` 表示输入，其余三个值分别对应三档输出速度。课件的 LED 例子通过 `CRL` 配置 PC0～PC7，使用 `MODE = 01`、`CNF = 00`，即 **10 MHz 通用推挽输出**。

**使用顺序**　先使能对应 GPIO 的 APB2 时钟，再选引脚和模式，最后读写。`GPIO_SetBits` 把指定输出位设为 1，`GPIO_ResetBits` 把它清为 0。灯是亮还是灭要看板上接法。
