## 4.1 GPIO概述及管脚命名

GPIO是General Purpose Input/Output，通用输入输出，是MCU与外部电路交换数字信息的基本模块。输入用于读取按键等信号，输出用于控制LED等设备；引脚还可能承担外设复用功能。

- GPIOA、GPIOB、GPIOC等表示端口。
- 每个端口最多16个引脚，编号0～15。PC6表示C端口的第6号引脚。
- 本课程STM32F103ZET6最多有112个GPIO；封装中的电源、复位等管脚不算普通GPIO。

 **【基础补充·位号与掩码】** 第 $n$ 位的掩码是`1U << n`。PC6的位号为6，掩码为`0x0040`，二者不能混用。`GPIO_Pin_6`就是选择第6位的掩码，而`GPIO_PinSource6`在引脚映射函数中表示编号6。

## 4.2 GPIO内部结构

按信号流向理解结构，比只背框图名称更有用。

-  **输入路径：** 外部引脚信号经输入电路送入输入数据寄存器IDR，CPU读取IDR判断电平。
-  **输出路径：** 普通输出模式由ODR的内容控制输出驱动电路，再作用到引脚。
-  **复用输出路径：** 外设（如定时器）提供输出信号，GPIO提供对应的引脚电气输出方式。
-  **上拉/下拉电阻：** 在输入未被外部明确驱动时，提供默认的高/低电平。
-  **模拟输入路径：** 用于连接模拟功能，数字输入部分按模拟模式要求关闭，减少不必要的影响。
-  **保护二极管：** 位于引脚与供电相关节点之间，用于相应的输入保护；其存在不意味着可以超出器件额定电压随意接线。
-  **P-MOS/N-MOS输出管：** 推挽方式利用上下驱动形成高低电平；开漏方式只主动下拉，关闭时由上拉等外部电路决定高电平。

 **【基础补充】施密特触发输入有助于提高对缓慢变化信号的抗干扰能力；推挽和开漏的区别则在输出驱动级。输入、输出、复用功能选择属于不同的控制环节。**

## 4.3 GPIO工作模式

 **【重点·八种模式总表】**

| 类别 | 标准外设库名称 | 主要特征 | 常见用途 |
| --- | --- | --- | --- |
| 模拟输入 | `GPIO_Mode_AIN` | 供模拟功能使用 | ADC输入 |
| 浮空输入 | `GPIO_Mode_IN_FLOATING` | 无内部上拉/下拉确定默认值 | 外部电路主动提供确定电平 |
| 上拉输入 | `GPIO_Mode_IPU` | 默认倾向高电平 | 另一端接地的按键 |
| 下拉输入 | `GPIO_Mode_IPD` | 默认倾向低电平 | 另一端接电源的按键 |
| 普通开漏输出 | `GPIO_Mode_Out_OD` | 能拉低，输出1时释放 | 需要上拉的共享信号线 |
| 复用开漏输出 | `GPIO_Mode_AF_OD` | 开漏驱动，信号由外设控制 | 硬件I2C等 |
| 普通推挽输出 | `GPIO_Mode_Out_PP` | 主动输出高或低电平 | LED、数码管控制 |
| 复用推挽输出 | `GPIO_Mode_AF_PP` | 推挽驱动，信号由外设控制 | USART发送、TIM PWM等 |

### 4.3.1 GPIO的工作模式—输入浮空模式

未使用内部上拉、下拉。外部必须给出可靠电平，否则悬空时读取结果可能不稳定。 **浮空不等于固定读0。**

### 4.3.2 GPIO的工作模式—输入上拉模式

内部上拉使未受外部驱动的引脚倾向于高电平。课件接地按键使用此模式：未按1，按下0。在STM32F1寄存器配置中，上拉/下拉输入共用同一CNF/MODE配置，具体由对应ODR位选择；ODR=1选上拉。

### 4.3.3 GPIO的工作模式—输入下拉模式

内部下拉使引脚默认倾向低电平。同样的输入配置下，ODR=0选下拉。若外部按键按下后接3.3V，则常对应松开0、按下1。

### 4.3.4 GPIO的工作模式—模拟输入模式

用于模拟信号输入，如ADC。不能把ADC电压测量理解为读取GPIO的0/1；GPIO数字输入只能判断逻辑电平，ADC才能把一定范围内的电压转换为多位数字值。

### 4.3.5 GPIO的工作模式—开漏输出模式

输出0时下拉管导通，把引脚拉低；输出1时下拉管关闭，呈高阻状态，由外部上拉等电路决定最终高电平。

 **【易错点】** “写1”在开漏模式中表示释放线路，不等于像推挽输出一样主动输出高电平。上拉电阻缺失时，引脚不一定得到稳定的高电平。

### 4.3.6 GPIO的工作模式—开漏复用输出模式

电气特性仍为开漏，但驱动信号来自外设。复用模式还需要外设初始化、时钟及正确的引脚映射，单独设置GPIO模式不能使外设自动工作。

### 4.3.7 GPIO的工作模式—推挽输出模式

通过上下输出驱动主动输出高电平或低电平。普通LED控制通常使用这种模式。对于本板共阳LED，低电平为“亮”、高电平为“灭”。

### 4.3.8 GPIO的工作模式—推挽复用输出模式

由定时器、USART等外设控制推挽驱动信号。例如第9章PC6/PC7输出TIM3 PWM时使用`GPIO_Mode_AF_PP`，不能仍按普通推挽模式处理。

## 4.4 GPIO输出速度

STM32F1提供2MHz、10MHz、50MHz三档输出速度。课件建议根据输出信号要求选择，LED、数码管、蜂鸣器等通常不需要最高档。

 **【重点·不能混淆】**

- 输出速度配置描述GPIO驱动能力和允许的切换速度档位。
- 实际引脚波形频率由程序改变电平的节奏，或外设时钟、分频及工作模式决定。
- 设置`GPIO_Speed_50MHz`不会自动产生50MHz方波；设置2MHz也不会把主频变成2MHz。

## 4.5 复用功能重映射

把某外设功能从默认引脚转移到芯片规定的备用引脚，称为复用功能重映射。重映射必须使用芯片支持的组合，不是任意把功能放到任何GPIO。

第9章示例使用TIM3完整重映射，将CH1、CH2放到PC6、PC7。应完成：开启GPIO和AFIO时钟→设置GPIO复用模式→配置重映射→配置并启动外设。

 **【易错点】** 普通GPIO模式选择、外设功能选择、重映射是相关但不同的操作。改变端口引脚名而不改重映射，外设输出不会自动搬过去。

## 4.6 GPIO控制寄存器

 **【重点·功能总表】**

| 寄存器 | 主要作用 | 需要掌握的规则 |
| --- | --- | --- |
| `GPIOx_CRL` | 配置0～7号引脚 | 每个引脚占4位 |
| `GPIOx_CRH` | 配置8～15号引脚 | 每个引脚占4位，从8号引脚重新按最低4位排列 |
| `GPIOx_IDR` | 读取引脚输入 | 低16位对应0～15号引脚 |
| `GPIOx_ODR` | 保存输出数据；上/下拉输入时参与方向选择 | 低16位有效，支持读写 |
| `GPIOx_BSRR` | 按位设置/清零ODR | 低16位写1置位，高16位写1清零；写0不操作 |
| `GPIOx_BRR` | 按位清零ODR | 低16位写1清零；写0不操作 |
| `GPIOx_LCKR` | 锁定引脚配置 | 锁定CRL/CRH相应配置，不是锁死输出电平 |
| `RCC_APB2ENR` | 使能APB2外设时钟 | GPIOC为bit4，AFIO为bit0 |

### CRL/CRH：MODE与CNF

一个引脚的4位从高到低为`CNF[1:0] MODE[1:0]`。

| MODE | 作用 |
| --- | --- |
| 00 | 输入模式 |
| 01 | 输出，最大10MHz |
| 10 | 输出，最大2MHz |
| 11 | 输出，最大50MHz |

| CNF | MODE=00时 | MODE非0时 |
| --- | --- | --- |
| 00 | 模拟输入 | 普通推挽输出 |
| 01 | 浮空输入 | 普通开漏输出 |
| 10 | 上拉/下拉输入 | 复用推挽输出 |
| 11 | 保留 | 复用开漏输出 |

 **常见4位配置值：** 模拟输入`0x0`；浮空输入`0x4`；上/下拉输入`0x8`；2MHz普通推挽`0x2`；10MHz普通推挽`0x1`；50MHz复用推挽`0xB`。它们由CNF与MODE组合得到，不是顺序编号。

 **【基础补充·位运算】**

| 操作 | C写法 | 效果 |
| --- | --- | --- |
| 置第n位为1 | `reg \|= (1U << n);` | 其余位保持 |
| 清第n位为0 | `reg &= ~(1U << n);` | 其余位保持 |
| 翻转第n位 | `reg ^= (1U << n);` | 0变1，1变0 |
| 检查第n位 | `(reg & (1U << n)) != 0U` | 得到逻辑判断结果 |
| 替换若干位 | `reg = (reg & ~mask) \| value;` | 先清目标位，再写新值 |

以上适用于普通可读写位； **不能把所有寄存器都按普通变量处理** 。BSRR为动作寄存器，EXTI的PR为写1清除标志，后续TIM标志又有不同清除规则。

### IDR、ODR、BSRR、BRR的区别

```c
uint32_t pc0_input = (GPIOC->IDR & 0x0001U); /* 外部引脚输入状态 */
uint32_t pc0_output = (GPIOC->ODR & 0x0001U);/* 输出数据锁存值 */

GPIOC->BSRR = (1U << 0);       /* ODR第0位置1，PC0输出高 */
GPIOC->BSRR = (1U << (0 + 16));/* ODR第0位清0，PC0输出低 */
GPIOC->BRR  = (1U << 0);       /* 同样使PC0输出低 */
```

`BSRR = 0`不代表全端口清零，而是没有任何位被操作。BSRR可一次写入完成所选位设置/清零，避免对ODR进行“读出→修改→写回”时干扰其他并发修改。不要对BSRR使用`|=`来保留旧动作。

 **【基础核对·LCKR】** LCKK=0表示锁键未激活，1表示激活。锁键序列是对选定锁定位执行LCKK写1、写0、写1，再读确认；成功后相关配置保持锁定直到下一次复位。课件把LCKK=0、1都写为“激活”属于文字问题。[ST RM0008](https://www.st.com/resource/en/reference_manual/cd00171190-stm32f101xx-stm32f102xx-and-stm32f103xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

## 4.7 GPIO寄存器配置实例

 **【重点·8个LED同时闪烁】** 本板LED接PC0～PC7，低电平亮。

1. 开GPIOC时钟：RCC_APB2ENR的bit4置1。
2. PC0～PC7配置10MHz普通推挽，每个引脚配置为`CNF=00, MODE=01`，即4位`0001`。
3. 八组`0001`拼成`0x11111111`，写入GPIOC_CRL。
4. 低8位写0点亮LED，写1熄灭LED。

```c
RCC->APB2ENR |= (1U << 4);  /* 0x10，只开启GPIOC这一位 */
GPIOC->BSRR = 0x00FFU;      /* 先把PC0～PC7预置为1 */
GPIOC->CRL = 0x11111111U;   /* 全部8个低引脚都属于本例目标 */

GPIOC->BRR = 0x00FFU;       /* PC0～PC7全为0，8灯亮 */
GPIOC->BSRR = 0x00FFU;      /* PC0～PC7全为1，8灯灭 */
```

课件用`RCC_APB2ENR=0x10`说明时钟位含义；实际已有其他外设时钟时，用`|=0x10`可保留其他使能位。

 **【基础补充·只改一个引脚】** PC3属于CRL，第3号引脚占bit15～12，所以移动位数为3×4=12：

```c
GPIOC->CRL = (GPIOC->CRL & ~(0xFU << 12)) | (0x2U << 12);
/* 清除PC3的4位，再写入0x2：2MHz普通推挽 */

GPIOC->CRH = (GPIOC->CRH & ~(0xFU << 0)) | (0x2U << 0);
/* PC8在CRH中占最低4位，移位数为(8-8)*4=0 */
```

通用计算规则：引脚 $n<8$ ，使用CRL且移位 $4n$ ； $n\ge8$ ，使用CRH且移位 $4(n-8)$ 。

## 4.8 寄存器版LED灯闪烁工程

### 4.8.1 创建寄存器版工程模板

课件删除不需要的ST_Driver和APP分组，直接在main中操作寄存器。仍需要正确的器件定义、启动和系统支持文件；“不用外设库函数”不等于不需要芯片启动配置。

### 4.8.2 LED灯闪烁程序设计

 **【讲解示例·完整main.c】** 依赖STM32F103大容量器件模板；不调用标准GPIO/RCC外设库函数。延时循环只演示亮灭，不标称精确秒数。

```c
#include "stm32f10x.h"

static void DelayLoop(uint32_t count)
{
    volatile uint32_t i;
    for (i = 0; i < count; ++i) { }
}

int main(void)
{
    RCC->APB2ENR |= (1U << 4);
    GPIOC->BSRR = 0x00FFU;
    GPIOC->CRL = 0x11111111U;

    while (1)
    {
        GPIOC->BRR = 0x00FFU;  /* 8个LED亮 */
        DelayLoop(600000U);
        GPIOC->BSRR = 0x00FFU; /* 8个LED灭 */
        DelayLoop(600000U);
    }
}
```

 **逐段理解：** `|=`只开启GPIOC时钟位；CRL每4位配置一个引脚；BRR写1使对应输出变0；BSRR低16位写1使输出变1；无限循环重复亮灭。PC8蜂鸣器和PC9以上引脚不会被这些按位输出操作改写。

### 4.8.3 基于寄存器开发方式特点

直接、可精确控制底层配置，适合底层开发和对资源有严格要求的场景；代价是必须熟悉寄存器地址、位定义与访问规则，移植和维护时需要仔细核对。库函数方式把这些配置细节封装起来，但理解寄存器仍有助于排错。

## 4.9 本章小结

 **必须能做的题型：**

- 给定按键/LED/ADC/PWM场景，选择GPIO模式并说明原因。
- 给定CNF、MODE，算出4位配置值；反过来解释`0x1`、`0x2`、`0x4`、`0x8`、`0xB`。
- 给定引脚号，确定使用CRL还是CRH以及移位数。
- 判断`ODR`、`BSRR`、`BRR`赋值后的引脚和LED状态。
- 解释为什么忘开GPIO时钟、模式选错或误写整个端口，会使程序“编译通过但运行不对”。

 **小练习答案：** PC0、PC1输出低，其余低8位输出高，应得到低8位`11111100`即`0xFC`；若用BRR，只需写`0x0003`清这两位，前提是其他灯已处于熄灭状态。
