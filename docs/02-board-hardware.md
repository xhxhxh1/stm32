## 知识点速查

### 芯片参数和型号

| 题目问的量 | 记法 |
| --- | --- |
| STM32F103ZET6 的引脚数 / GPIO 数 | **144 个总引脚 / 最多 112 个 GPIO** |
| 最高主频 / 板上主晶振 | **72 MHz / 8 MHz**。32.768 kHz 晶振用于 RTC |
| 程序和运行数据 | **512 KB Flash** 通常存放程序，掉电保留。**64 KB SRAM** 存放运行数据，掉电丢失 |
| 型号字母 | 引脚位置的 `C / R / V / Z` 分别表示 48 / 64 / 100 / 144 脚。容量位置的 `8 / E` 分别表示 64 / 512 KB Flash。`T` 是 LQFP，尾部 `6` 是 −40～85 ℃ |
| `F` 与 `103` | `F` 为通用类型，`103` 是增强型产品线。比较 ZET6 和 C8T6 时，应逐位区分引脚、Flash 和封装 |

### 启动和电路

- **主 Flash 启动**时 BOOT0=0，BOOT1 任意。BOOT0=1 时才由 BOOT1 区分系统存储器（0）和 SRAM（1）。
- **复位看 NRST。** 拉低 NRST 使芯片复位。GPIO 挂在 **APB2**，使用端口前要开对应时钟。
- **电平看器件与板上接法。** 本板 MCU 供电为 3.3 V，5 V 容忍要查对应引脚的 FT 标记及使用条件。课件板 LED 低电平亮，接地按键在上拉输入时按下读 0。[STM32F103ZET6 器件数据手册](https://www.st.com/resource/en/datasheet/stm32f103ze.pdf)

## 题型练习

1. **单选**　STM32F103ZET6 的 GPIO 数量是多少？

   A. 64　B. 112　C. 144　D. 512

2. **多选**　哪些 BOOT0、BOOT1 的组合能从主 Flash 启动？

   A. 0、0　B. 0、1　C. 1、0　D. 1、1

3. **判断**　STM32F103C8T6 中的 103 表示 103 个引脚。

<details>

<summary>展开答案与理由</summary>

1. **B。** 144 是总引脚数。
2. **AB。** 主 Flash 启动只要求 BOOT0=0。
3. **错。** 103 是产品线编号，引脚数由该位置的 C 指示，共 48 脚。

</details>

### 2.1 开发板总体概况

<details>

<summary>展开本节详解</summary>

#### 2.1.1 开发板设计背景

开发板用于把芯片理论与实际实验结合，覆盖经典单片机项目，适合ARM初学者及从8位单片机转入32位单片机的学习者。课件按“电源→核心板→I/O→扩展模块”的顺序介绍电路。

#### 2.1.2 开发板总体介绍

**【重点·前九章用到的连接】**

| 部件 | 课件连接 | 复习时必须判断 |
| --- | --- | --- |
| L1～L8 | PC0～PC7 | 共阳连接，输出低电平点亮 |
| KEY1～KEY4 | PE0～PE3，按键另一端接地 | 上拉输入时，松开1、按下0 |
| 无源蜂鸣器 | PC8经PNP三极管驱动 | PC8低电平导通，交替驱动发声 |
| 数码管段选 | PG0～PG7对应a～g、dp | 共阳段码中0表示点亮 |
| 六位数码管位选 | PE15、PE14、PE13、PE12、PE11、PE10 | 经PNP驱动，低电平选中 |
| PWM呼吸灯 | PC6、PC7上的L7、L8 | TIM3完整重映射后的CH1、CH2 |

**【基础补充】同一管脚可以有多种功能，但一个具体时刻的配置和电路连接必须一致。** 例如PC6既可做普通GPIO控制LED，也可由TIM3输出PWM；PE0作为普通按键输入后，还可映射到EXTI0。

</details>

### 2.2 电源模块

<details>

<summary>展开本节详解</summary>

#### 2.2.1 电源模块原理图

课件提供USB接口供电和“火牛接口”供电两种方式，系统使用3.3V电源为MCU及相应电路供电。要认识电源输入、稳压后电源和地的区别。

原理图中S1用于电源通路选择/控制，U1为REG1117-3.3稳压器，把所示+5V支路转换为+3.3V；输入、输出侧均画有220μF与0.1μF电容，D1与470Ω电阻构成电源指示支路。 **读图顺序：电源入口→开关→稳压输入→稳压输出→负载与地。** 外接电源规格应按实际电路要求选择，不能仅凭“火牛接口”理解为任意电压都可输入。

**【基础补充·电压与电流】** 电源电压决定电位差，电流由负载和电路决定。板上引出了5V，并不表示STM32的供电引脚可接5V；GPIO的5V容忍能力也不等于MCU能用5V供电。两个相连数字电路通常需要共同的地作为电平参考。

</details>

### 2.3 核心板电路

<details>

<summary>展开本节详解</summary>

#### 2.3.1 CPU模块

**【重点·STM32F103ZET6参数】**

| 参数 | 本课程型号 |
| --- | --- |
| 内核、最高主频 | 32位ARM Cortex-M3，72MHz |
| 性能特征 | 课件列1.25DMIPS/MHz、单周期乘法、硬件除法 |
| 存储器 | 512KB Flash、64KB SRAM |
| 封装、引脚 | LQFP144；最多112个GPIO |
| 供电范围 | 2.0～3.6V，开发板使用3.3V |
| 低功耗模式 | 睡眠、停止、待机 |
| 定时器 | TIM2～TIM5通用；TIM1/TIM8高级；TIM6/TIM7基本；2个看门狗；1个24位SysTick |
| 模拟外设 | 3个12位ADC（最多21通道），2个12位DAC，内部温度传感器 |
| 其他 | RTC，12通道DMA，96位唯一编号 |
| 通信资源 | 2个I2C、3个SPI（部分复用I2S）、CAN、5个USART/UART、USB、SDIO |
| 工作温度 | −40℃～85℃ |

**【易错点】** 144是总管脚数，112是GPIO数量，不能相等看待；SysTick为24位减计数器，课件的TIM1～TIM8为16位定时器。

**【基础核对】** 片内8MHz时钟来自RC振荡器，外部8MHz器件才是课件板上的晶振；不要把“内部RC”写成“内部晶体”。芯片支持的5V容忍引脚要以数据手册的FT标记及使用条件为准，模拟引脚尤其不能因“多数GPIO容忍5V”而直接接5V。[ST器件数据手册](https://www.st.com/resource/en/datasheet/stm32f103ze.pdf)

#### 2.3.2 串口通信模块

核心芯片为CH340G，实现USB与串口之间的转换。电脑侧通过USB连接，MCU侧使用串行信号。 **【基础补充】** CH340G承担接口转换，不是MCU本身；USB供电、USB转串口通信和通过调试器下载程序是不同功能。

#### 2.3.3 外接晶振模块

| 晶振 | 频率 | 作用 |
| --- | --- | --- |
| Y2系统主晶振 | 8MHz | 提供系统时钟的外部振荡源 |
| Y3实时时钟晶振 | 32.768kHz | 为RTC计时提供低速时钟 |

晶振两端分别接22pF对地电容。理解“晶振频率”与“内核主频”不是同一个数。

**【基础补充·时钟链】** 在外部8MHz经PLL倍频9倍、系统及AHB不再分频的配置下：

$$
f_{SYSCLK}=8\ \mathrm{MHz}\times9=72\ \mathrm{MHz}
$$

这是一组常见配置条件，72MHz不会仅因插上8MHz晶振就自动成立。后续延时和定时器计算必须与实际时钟配置一致。

32.768kHz=32768Hz= $2^{15}$ Hz，便于经整数分频得到1Hz；本章只需认识它与RTC的关系。

#### 2.3.4 备用电源模块

使用3V的CR1220纽扣电池，为RTC及备份存储器供电。 **【易错点】** 备用电池维持的是备份域相关功能，不表示主电源断开后整个MCU及所有LED仍继续运行。

#### 2.3.5 ADC模块电源

VDDA为模拟供电，VSSA为模拟地；VREF+、VREF−为转换参考电压。课件中VDDA、VREF+接3.3V，VSSA、VREF−接地。掌握名称和连接关系即可，详细ADC转换留在后续课程范围。

#### 2.3.6 CPU滤波电路

C12～C19共8个0.1μF电容用于CPU电源滤波。 **【基础补充】** 0.1μF=100nF；这些电容帮助抑制电源上的快速波动，不能当作软件延时器件。数字电路切换时会产生瞬态电流，电源去耦有助于稳定工作。

#### 2.3.7 复位电路

STM32采用低电平复位，支持上电复位和按键复位。复位用于使芯片回到规定的初始状态，然后重新执行启动过程。

**【基础补充】** 复位不等于擦除Flash中的程序。重新启动后，程序按初始化代码重新设置GPIO、变量和外设；需要掉电保留的数据应放在合适的非易失存储器中。

#### 2.3.8 启动设置电路

通过BOOT0、BOOT1跳线选择启动位置。

| BOOT1 | BOOT0 | 启动位置 | 理解 |
| --- | --- | --- | --- |
| X | 0 | 用户Flash | 常规运行用户程序 |
| 0 | 1 | 系统存储器 | 运行芯片厂家提供的启动程序 |
| 1 | 1 | 内置SRAM | 从SRAM启动，常用于特定调试情形 |

X表示该位对这一行的选择结果无影响。 **【重点】** 正常运行已写入Flash的程序时，BOOT0应为0。启动选择与“把程序下载到了哪里”必须对应。

</details>

### 2.4 IO模块电路

<details>

<summary>展开本节详解</summary>

#### 2.4.1 LED指示灯模块

8个LED阳极经限流电阻接3.3V，阴极接PC0～PC7，因此是低电平有效。

- PCx=0：形成从3.3V经电阻、LED到GPIO的电流通路，LED亮。
- PCx=1：LED两端压差不足以按正常方式导通，LED灭。

**【基础补充·限流电阻】** 忽略次要误差时：

$$
I_{LED}\approx\frac{V_{CC}-V_F-V_{OL}}{R}
$$

 $V_{CC}$ 为电源电压， $V_F$ 为LED正向压降， $V_{OL}$ 为GPIO低电平输出电压， $R$ 为串联电阻，电压用V、电阻用Ω时电流单位为A。假设3.3V、LED压降2.0V、忽略 $V_{OL}$ 、电阻330Ω，则 $I\approx3.94$ mA。 **这是说明计算方法的假设算例，不是原板电阻实测值。**

#### 2.4.2 按键模块

四个按键一端接地，另一端分别接PE0～PE3。配置上拉输入后，松开时内部上拉使引脚为1，按下时接地变为0。不能把“按下”直接理解成逻辑1。

**【基础补充】** 机械按键按下和松开都可能抖动，需要硬件或软件消抖，第6章给出完整处理示例。

#### 2.4.3 数码管模块

六位共阳数码管采用动态扫描。段选控制“显示哪个数字”，位选控制“在哪一位显示”。共享段线时，每次应选中一位，快速循环扫描六位。

#### 2.4.4 蜂鸣器模块

无源蜂鸣器BUZ1由PC8经PNP三极管Q7驱动。PC8拉低使三极管导通；拉高使其截止。

**【基础补充】** 无源蜂鸣器需要交变驱动才能持续形成音调，频率主要影响音高；不能把PC8长期置0当作完整的发声控制。三极管承担负载驱动，GPIO提供控制信号。

#### 2.4.5 OLED显示屏电路

课件使用0.96寸OLED12864显示屏。“12864”表示128×64的显示点阵规格。本次前九章复习只保留硬件认识，不展开后续OLED通信编程。

</details>

### 2.5 扩展模块电路

<details>

<summary>展开本节详解</summary>

课件有的页面使用 1.5 编号，本节按第 2 章统一为 2.5。

#### 2.5.1～2.5.2 温度传感器与红外传感器

认识DS18B20温度传感器和红外接收头。课件强调其接线较简单； **【基础补充】** DS18B20的单总线协议与红外接收头输出的编码脉冲不是同一套通信协议，不能因都用一根信号线就混为同类协议。

#### 2.5.3 A/D采样模块

提供4路可调电压，供ADC采样并转换成数字量。复习时识别“模拟电压输入→ADC→数字数据”的方向。

#### 2.5.4 EEPROM存储器

AT24C02用于保留重要数据和系统配置，通过模拟I2C与MCU连接。 **【基础补充】** EEPROM具有掉电保持能力，与SRAM中的普通变量不同。

#### 2.5.5 I/O引脚外接模块

开发板将部分I/O、5V、3.3V电源引到两侧排针，便于连接外部电路。连接时应依据具体引脚名称、功能和电平范围判断，不能只凭排针位置猜测。

</details>
