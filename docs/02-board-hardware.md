## 2.1 STM32F103ZET6 的基本参数

| 参数 | STM32F103ZET6 |
| --- | --- |
| 内核和最高工作频率 | Cortex-M3，**72 MHz** |
| 封装和总引脚数 | LQFP144，**144 脚** |
| 通用 I/O 数量 | 最多 **112 个 GPIO**，端口挂在 APB2 |
| 片内 Flash | **512 KB**，通常保存程序，可掉电保留 |
| 片内 SRAM | **64 KB**，用于运行时数据，掉电后内容丢失 |
| 工作电压 | 芯片供电范围 **2.0～3.6 V**，课件板使用 **3.3 V** |
| 模数和数模转换 | **3 个 12 位 ADC**、**2 个 12 位 DAC**。ADC 把模拟量转换成数字量，DAC 把数字量转换成模拟量 |

拆读 `STM32F103ZET6` 时，`F` 是通用型，`103` 是增强型产品线。`Z` 指 144 脚，`E` 指 512 KB Flash，`T` 指 LQFP，`6` 指 −40～85 ℃。同一字段位置的 `C`、`R`、`V` 分别表示 48、64、100 脚。`C8T6` 中的 `8` 表示 64 KB Flash。

课件列出的三种低功耗模式是**睡眠、停止、待机**。芯片内部还带温度传感器和 RTC（实时时钟）。

## 2.2～2.3 电源、时钟、复位和启动

- **供电**　实验板可用 USB 或外接电源供电，经稳压得到 3.3 V。能否承受 5 V 输入要按具体引脚查数据手册中的 FT 标记。
- **时钟**　HSI 是片内 8 MHz RC 时钟。课件板的 HSE 外接 **8 MHz** 晶振，LSE 外接 **32.768 kHz** 晶振供 RTC 使用。
- **复位和备用电源**　NRST 低电平有效。板上支持上电复位、按键复位。主电源断开后，纽扣电池通过 VBAT 给 RTC 和备份域供电。
- **串口转换**　CH340G 在电脑的 USB 和单片机的串口之间转换信号。

| BOOT0 | BOOT1 | 启动位置 |
| --- | --- | --- |
| 0 | 任意 | 主 Flash，通常用来运行用户程序 |
| 1 | 0 | 系统存储器，执行厂家内置引导程序 |
| 1 | 1 | 片内 SRAM |

课件板用跳线帽设置 BOOT0、BOOT1。复位后按表中对应的方式启动。

## 2.4～2.5 课件板上的常见器件

| 器件 | 接法和有效电平 |
| --- | --- |
| L1～L8 | 接 PC0～PC7，阳极经电阻接 3.3 V，**低电平亮** |
| KEY1～KEY4 | 接 PE0～PE3，另一端接地。配置上拉输入后，**按下读 0** |
| 无源蜂鸣器 | PC8 控制 PNP 三极管，低电平导通 |
| 六位共阳数码管 | PG0～PG7 送段码，PE15～PE10 控制位选 |

| 扩展模块 | 用途 |
| --- | --- |
| OLED | 课件板使用 0.96 英寸、128×64 的显示屏 |
| DS18B20 | 外接温度传感器，使用单总线与单片机通信 |
| A/D 采样电路 | 提供 4 路可调电压供 ADC 采样 |
| AT24C02 | 用 EEPROM 保存掉电后还要保留的配置和数据，课件板用模拟 I²C 读写 |
