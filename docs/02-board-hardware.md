# 第 02 章 STM32 开发板硬件系统

## 2.1～2.3　让芯片运行起来的几个条件

课件用的 STM32F103ZET6 最高主频为 **72 MHz**，片内有 **512 KB Flash** 和 **64 KB SRAM**。程序通常存放在掉电后仍能保存内容的 Flash 中，运行时的变量通常放在 SRAM。

| 板上部件 | 作用 |
| --- | --- |
| 电源与备用电池 | USB 或外接电源给板子供电，板上稳压得到 3.3 V。备用电池维持实时时钟和备份域 |
| 两个晶振 | 8 MHz 主晶振可作为系统时钟源，经配置可得到更高主频。32.768 kHz 晶振用于 RTC 计时 |
| 复位与启动引脚 | NRST 拉低使芯片复位，BOOT 引脚决定复位后从哪里启动。正常运行片内程序时 BOOT0 置 0 |
| CH340G | 在电脑的 USB 和单片机的串口之间转换信号 |

## 2.4～2.5　看接线判断有效电平

- **LED**　L1～L8 的阳极经限流电阻接 3.3 V，阴极接 PC0～PC7。对应引脚输出低电平时，电流流过 LED，灯亮。
- **按键**　KEY1～KEY4 接 PE0～PE3，另一端接地。配置上拉输入后，松开读 1，按下读 0。
- **蜂鸣器与数码管**　PC8 经 PNP 三极管控制无源蜂鸣器。六位共阳数码管用 PG0～PG7 送段码，用 PE15～PE10 选位。

读程序时先看板上接法。例如，`GPIO_ResetBits(GPIOC, GPIO_Pin_0)` 的直接作用是将 PC0 置低，在这块板上就会点亮 L1。
