## 10.1 通信方式与数据帧

| 概念 | 基本区别 |
| --- | --- |
| 串行、并行 | 串行依次传一位，并行通过多条数据线同时传多位 |
| 同步、异步 | 同步按共同的时钟节奏传输，异步通过约定的波特率和起始位对准每一帧 |
| 单工、半双工、全双工 | 单工单向传。半双工双向轮流传。全双工可同时收发 |
| 奇校验、偶校验 | 数据位加校验位中，1 的总数应为奇数或偶数 |
| 累加和、CRC | 累加和检查约定数据的和，CRC 用约定的除法余数校验数据块 |

**8N1** 是 8 个数据位、无奇偶校验、1 个停止位。加上 1 个起始位，一帧共 **10 位**。异步串口空闲为高，起始位为低，停止位为高，数据最低位先发送。9600 波特的 8N1 帧约需 `10 ÷ 9600 ≈ 1.04 ms`。

## 10.2～10.3 USART 寄存器与标志

USART 是通用同步/异步收发器。`SR` 保存状态，`DR` 用于读写数据，`BRR` 设置波特率。

| 标志 | 置位时的含义 |
| --- | --- |
| `TXE` | 发送数据寄存器空，可以写下一个数据 |
| `TC` | 本次发送完成，包括最后的停止位 |
| `RXNE` | 接收数据寄存器非空，有数据可读 |

## 10.4 USART1 和课件例子

USART1 使用 APB2 上的 PCLK2，默认 PA9 发送，配置为复用推挽输出。PA10 接收，课件配置为浮空输入。收发双方要设定相同的波特率、数据位、校验和停止位。

`USART_SendData` 写入待发送数据，`USART_ReceiveData` 读取接收数据，`USART_GetFlagStatus` 查询标志。课件的校时例子按时、分、秒发送三个数值字节，HEX 输入 `0A 12 1E` 就是十进制的 10、18、30。
