# 第 07 章 数码管动态显示

## 7.1　段选决定数字，位选决定位置

一位数码管由 a～g 七段和小数点 dp 组成。**共阴**把阴极接在一起，段线给高电平时相应段亮。**共阳**把阳极接在一起，段线给低电平时相应段亮。课件板使用六位共阳数码管。

| 控制信号 | 课件连接 | 例子 |
| --- | --- | --- |
| 段选 | PG0～PG7 对应 a～g、dp | 数字 1 只亮 b、c 两段，低八位写 `0xF9` |
| 位选 | PE15～PE10 分别控制第 1～6 位 | PE15 置低，选中第 1 位 |

**怎样推出 `0xF9`**　按 `dp g f e d c b a` 从高位排到低位，把 c 和 b 写成 0，其余写 1，得到 `11111001`。同一个段码保持不变，换位选，就能把数字显示在另一位。

## 7.2～7.4　六位数字为什么看似同时点亮

静态显示让各位持续保持自己的段码。动态显示让多位**共用段线、轮流点亮**。一次扫描可以先关闭上一位，再送新段码、打开目标位，短暂停留后切换下一位。六位循环得足够快，人眼就看到稳定的整组数字。若换段时上一位仍亮，容易出现重影。

```c
GPIO_ResetBits(GPIOE, GPIO_Pin_15);  // 段码已送好，拉低 PE15 让第 1 位显示该数字
```

课件把同一原理用于显示时间。比如分钟值为 37，`minute / 10` 取十位 3，`minute % 10` 取个位 7，再分别查段码、送到对应位置。
