## 内容标记

- **【重点】**：根据课件整理的核心知识，不代表教师另行公布的考试范围。
- **【基础补充】**：为理解课件加入的时钟、计数、边界及C语言解释。
- **【讲解示例】**：按课件硬件和任务整理的教学代码；改写的参数范围会明确说明。
- **【易错点】**：时钟倍频、寄存器值加1、PWM模式与极性、有效电平等容易混淆的地方。

## 代码与公式的使用条件

代码围绕**STM32F103ZET6 + STM32F10x标准外设库 + 课件配套开发板**组织。延时示例假设HCLK为72 MHz，定时器算例假设TIM输入时钟为72 MHz；板卡或时钟配置改变后需要重新核对。

笔记保留全部章节内容、C代码块和数学公式。主要示例此前已通过语法及标准库接口编译检查，未完成整工程链接、烧录或实机验证。示例的两个`main.c`分别对应计时项目和PWM项目，应分开使用。

资料来源为用户提供的STM32课程PPT及此前整理的详细笔记；基础核对所用的ST参考手册链接保留在正文中。
