# STM32 基础复习（第 1～10 章）

按课程 PPT 的章节顺序整理。深度参考平时的单选、多选和判断题，涵盖每章的基本概念、常见参数和容易混淆的说法。芯片和引脚示例对应课件配套的 STM32F103ZET6 开发板。
